## 核心结论摘要

### 事业编

1. 进面线 ≠ 录取线。150 个岗位实测，**录取最低笔试分比进面线平均高 7.5 分（中位）**；招 1 人 +8.8 分，招 3 人 +6.0 分。
2. **招录人数杠杆**：进面比例 1:3，招 3 人取第 9 名，招 1 人取第 3 名。同专业同城岗位里优先选招录人数多的。
3. 该规律**只在专业条件窄的岗位成立**；全岗位层面因「专业不限」宽口径岗稀释而不成立。
4. 「限应届」在事业编里反而更贵（2026 年均值高 23.7 分），因为限应届岗少且位置好。

### 江西省考

1. 应届身份的价值约 **3.5–5.6 分**（控制层级/专业/同单位同岗位名后），全省不控制变量只差 0.4 分是假象。
2. 真正的差别在**分布**：低分档（≤130）几乎只有应届岗。
3. 省考 2401 个普通岗里 2272 个只招 1 人，**事业编的名额杠杆在省考用不上**。
4. 江西省考按「当届」执行，不适用择业期。

### 只按本人条件筛（2026 职位表实筛）

1. **严格可报 320 个岗**（专业对口 + 条件全对得上），其中 2027 年能报（不限应届）**147 个**。
2. 这 147 岗进面线中位 **142.02**；**129 分能进面 0 个**，132 分 2 个，138 分 21 个，141 分 62 个。
3. 留丰城：可报 5 岗，最低 **140.66**（丽村镇），需提 11.7 分。
4. 省考的应届差 **4.42 分**（限应届中位 137.60 vs 不限 142.02）；但**岗位数差距更致命**——南昌 14 个计算机对口岗里 8 个是应届专岗，无应届身份只剩 1 个（149.01）。
5. 另有 132 个计算机对口岗要求中共党员（群众出局）、75 个限男性（含监狱民警最低 118.30 分招 2 人）。


## 口径说明

- 分数统一为笔试分（事业编 300 分制 / 省考 200 分制），跨年度不做绝对分直接对比，看同年度分位与结构。
- 「进面线」= 官方入闱面试名单中该岗位最低分；「录取分」= 各厅局体检人员名单中的笔试成绩。
- 岗位表、职位表、入面名单均为官方原始 xls/xlsx 附件，脚本解析后逐条配对。
